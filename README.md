# Tennis Court Watcher

葛飾区・浦安市の公共テニスコート公開空き状況モニター。
ログイン、予約、申込トレイ操作は行いません。

## 対象と実行

- 浦安：全8施設28面。今日〜7日先（両端含む）の土日祝。
- 葛飾：全8施設36面。今日〜翌月同日（存在しない日は月末）の土日祝。
- 日本の祝日・振替休日・国民の休日は `holidays` で判定。
- 既存の15分間隔（UTC各時02・17・32・47分）を維持。GitHubの混雑で開始が遅れることがあります。
- 葛飾は公開システム稼働時間7〜24時に確認し、稼働時間外は前回状態を保持。

## 判定

浦安は「目的から探す」→テニスで全施設を一括表示。施設ごとの `.koma-area` を読み、28面全てと日付・年・月を検証します。別々の表に分かれた時刻見出しと面のセルは、描画された境界で対応させます。●・〇・○だけを空きとして扱い、×・受付期間外・休館は通知しません。

葛飾は「施設の空き状況」→「利用目的から」→「屋外スポーツ」→「テニス」。各施設の月間カレンダーの対象日を調べ、「全て空き」「一部空き」だけ日別表示を開きます。日付・施設・面数・時刻列を確認し、日別セルの画像altが正確に「空き」の枠だけを抽出。1830-2030や1800-2100など、画面にある開始・終了時刻をそのまま使います。

## 通知と障害

- 新規空き、または実際に埋まったと確認した後の再公開だけIssueを作り、`kobadaitennis-art` にアサイン。
- 同一の自治体・日付・施設・面・時間を正規化して重複排除。
- 通知送信後に状態を保存。送信・pushの途中で失敗しても、Issue内の枠別イベントマーカーで重複送信を防止。
- 確認失敗は「空きなし」に変換しません。成功した施設・日付のみ状態を更新し、失敗範囲の状態は保持。他方の自治体の確認も続けます。
- 空き以外のIssueは作りません。障害と確認範囲はActions Summaryと `latest-check` アーティファクトで確認できます。
- 現在時刻より前に始まった枠は通知しません。

## 検証

Actions → Tennis court watcher → Run workflow で `dry_run` をチェックすると、実サイトの取得と解析だけを検証できます。Issue作成と状態更新は行いません。

通常の実行では毎回 `python -m unittest discover -s tests -v` を実施します。
`data/latest.json` に全施設×対象日の確認範囲とエラーを記録します。ジョブが成功していても `success: false` の場合は確認不完全です。

通知後に枠が埋まることがあります。予約前に各自治体のサイトで再確認してください。
